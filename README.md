# Case Trainee — Wolfbotz IEEE

## Sobre o projeto

Desenvolvimento de um robô autônomo como parte do processo trainee da extensão Wolfbotz IEEE, com o objetivo de implementar sistemas de detecção de adversários, desvio de bordas e seguimento de linha.

## Objetivos por subárea

### Programação

Desenvolver o software responsável pelo funcionamento autônomo do robô, utilizando uma linguagem de programação adequada para interpretar os sinais dos sensores e controlar os motores.

**Principais objetivos:**

* Implementar a leitura e interpretação dos sinais dos sensores.
* Desenvolver algoritmos para detectar e atacar o adversário.
* Implementar mecanismos de detecção das bordas da arena e prevenção de saídas.
* Desenvolver um código adicional para o comportamento de seguidor de linha.
* Integrar os sensores, o processamento e o controle dos motores.

### Eletrônica

Projetar e construir o circuito elétrico do robô, integrando os componentes eletrônicos necessários para garantir seu funcionamento adequado.

**Principais objetivos:**

* Selecionar e integrar os sensores de proximidade, borda e linha.
* Integrar o microcontrolador, os motores e os demais componentes eletrônicos.
* Desenvolver o esquemático elétrico do projeto.
* Realizar a prototipagem e o projeto dos circuitos.
* Verificar o funcionamento e a compatibilidade elétrica dos componentes.

### ⚙️ Mecânica

Desenvolver a estrutura física do robô, considerando as dimensões máximas estabelecidas no projeto e os requisitos de montagem.

**Principais objetivos:**

* Projetar o chassi do robô respeitando as dimensões máximas de 10 × 10 cm.
* Desenvolver modelos tridimensionais das peças necessárias para a montagem.
* Preparar os componentes mecânicos para impressão 3D.
* Garantir que o chassi comporte adequadamente os componentes eletrônicos e mecânicos.



## Estrutura do repositório

* `src/`: códigos-fonte do robô.
* `docs/`: documentação técnica, arquitetura, pinagem e registros de testes.

## Desenvolvimento

O desenvolvimento é realizado de forma colaborativa entre as subáreas de Programação, Eletrônica e Mecânica, com integração dos sistemas e testes progressivos para alcançar os objetivos do projeto.
