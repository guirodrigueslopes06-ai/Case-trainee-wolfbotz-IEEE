# Case Trainee — Wolfbotz IEEE

## Sobre o projeto
Desenvolvimento de um robô autônomo para
competições de sumô,
como parte do processo trainee da extensão
Wolfbotz IEEE.

## Objetivos
- Detectar e identificar o adversário.
- Atacar o oponente.
- Detectar as bordas da arena e evitar sair dela.
- Seguir trajetos determinados por linhas no chão.

## Tecnologias
- C++ / Arduino
- Git e GitHub
- Arduino IDE

## Estrutura do repositório
- `src/`: códigos-fonte do robô.
- `docs/`: documentação técnica, arquitetura e testes.

## Desenvolvimento
O código é desenvolvido de forma colaborativa,
com controle de versões pelo Git e GitHub.
